# SoleChem — Global Authorized Chemical Distributor

🌐 **[solechem.com](https://solechem.com)**

SoleChem is a globally authorized **B2B chemical distribution** company, providing high-quality chemical raw materials to industries worldwide. This repository contains the source code for the official SoleChem website.

---

## 🧪 About SoleChem

SoleChem serves as a trusted partner for businesses seeking reliable chemical supply chains. We specialize in:

- **Chemical Raw Materials** — A comprehensive catalog of industrial chemicals
- **Global Distribution** — Worldwide shipping and logistics network
- **B2B Solutions** — Tailored services for businesses of all sizes
- **Quality Assurance** — Products sourced from certified and authorized manufacturers
- **Technical Support** — Expert guidance on product selection and applications

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or later)
- **npm**

### Installation

```bash
# Clone the repository
git clone https://github.com/odayesmael/solechemEN.git
cd solechemEN

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:3000`

### Build for Production

```bash
npm run build
npm run preview
```
